## Review and limitations

Independent source review found and corrected: explicit OMM disable/no-OMM
rebuild instead of missing KHR shader execution mode; query-to-in-place-AS-update
WAR dependency plus compaction/property-query edges; split routing table;
dense forward MV requires correspondence inversion, not current-pixel negation.
KHR OMM uses AS objects and device_address_commands, EXT uses VkMicromapEXT,
with different host/query behavior; not a suffix swap.

Host reference policies are deliberately narrow test examples, not a complete
Vulkan validity checker. Shader compilation, real Vulkan correctness, semantic
model acceptance and mobile visual quality are not interchangeable. Read the
final acceptance JSON and raw logs for actual executed scope; do not infer PASS
from this traceability table. Roll back by reverting paired PR commits and
restoring release-contract to the preceding reviewed SHA; do not rewrite main.
