## C0–C8 deliverable accounting

- C0: pair/source snapshots and 36-task registry implemented. Complete normalized
  inclusion denominator remains open; vk.xml extraction and 1.4.309 test normative
  excerpts have explicit distinct snapshot identities, not falsely one uniform spec.
- C1: many actual family contracts and repaired contradictions exist. Full stable
  core/extension/SC semantics and the complete review denominator remain open.
  Hardware absence does not exempt writing query/reject/fallback knowledge.
- C2: generic rules are not exhaustive API decisions. The present sample-count
  milestone connects actual support/enables/allocations/output to bounded choices,
  while ten original decision families still need individual completion.
- C3: real Validation, shader tools and CPU Perfetto data exist; CPU spans are not
  GPU timings. Shader-access heuristic OFF missed a known RAW; retain that gap.
  RenderDoc/replay and physical counter capture remain unverified.
- C4: authored failures, minimal patches and semantic controls exist; not an
  independently sourced external engine repair or blind model solve. Preparing a
  traceable open-source task is possible locally and must not be called blocked
  simply because no source has yet been selected.
- C5: bounded endpoint correctness and requested allocation size are measurable
  now. This is not edge antialiasing quality, residency/peak VRAM, bandwidth,
  GPU/full-frame time, energy or thermal stability.
- C6: owned-process budget/cancel/recovery is real; it is not GPU hang/device-lost
  recovery. Noncoherent memory, FD semaphore/fence, Video and special extension
  execution are absent on this ICD. OOM/driver-fault simulations must stay labeled.
- C7: success candidates, explicit review/scope/expiry/revoke and controlled
  interruption observations exist. True unreproduced defect import and external
  review remain open; hash chains are not authenticated latest-state services.
- C8: exact-pair CI, deterministic text package and review receipts exist. Model
  Live/blind, historical 12-task same-model token comparison and final four seals
  have not passed. No zero-diagnostic or skipped test upgrades those states.

## Prioritized executable queue (not an indefinite list of similar experiments)

1. **Current bounded convergence milestone, local:** fixed same-scene1→4→1 runs,
   independent raw replay checks, actual enables/sample/format/allocations, strict
   sample-count/budget decision and explicit unknown objectives. Preserve source,
   tool, device, input and final-image comparability; demonstrate actual baseline
   restoration. Exit: positive+negative+tamper tests, independent audit, exact-pair
   run, full regression/CI, package integrity. No new parallel agent platform.
2. **P0 knowledge closure, local:** enumerate unresolved stable families against
   the frozen scope; assign exact existing knowledge locations, owners, source
   anchors and acceptance predicates. Review contradictions systematically rather
   than claiming a few corrected cards close full L2. Exit: machine-checkable full
   inclusion denominator and explicit reviewed/unreviewed matrix, not route counts.
3. **P1 real task preparation, local:** select a traceable original open-source
   engineering defect under an authorized repo, preserve original build/failure,
   separate reviewer oracle from solver input and define rollback/regression.
   Exit of preparation is a task package, NOT blind success. Existing authored
   examples must not be relabeled external sources.
4. **P1 integration convergence, local:** bring useful actual tools through a
   small number of source-paired user entries/handoffs; maintain completed prefix,
   cancellation and bounded evidence behavior. Do not create more unrelated tiny
   API demos merely to raise test totals or claim unmeasured tool capabilities.
5. **External execution gates:** authorized Live model/host with task isolation;
   supported physical/mobile/second-driver devices; thermal/power/present/input
   measurement access. Missing these blocks corresponding execution gates, not
   local knowledge/contract/source preparation. No credential or device request is
   made automatically by this document.

## Stop rules and four separate seals

After the sample-choice milestone, stop expanding similar draw fixtures. Next work
must close a named semantic denominator, actual external-task preparation or user
integration gap with a measurable exit. Do not claim this is the last local task:
C0/C1 and task preparation still require real work.
