## Fallbacks and explicit deferred work

FP32 SSBO state, no-float-atomic graph coloring/contribution-gather and legacy single-queue synchronization are the exercised baseline. CPU state production or static snapshot is a documented engine fallback, not a second rendering API. Optional async/atomics/FP16/AS/soft-body paths remain UNIMPLEMENTED. Android Adreno and Mali, sustained temperature/energy traces, actual host integration and current-model Live responses remain NOT_RUN. Source presence and static PASS must not promote these layers.

## Structure and release

Eight modules, 197 knowledge files, 200-file runtime package ceiling. No new startup reads or hard rules. Evaluation source, exact plan, source ledger, prompts and raw results live only in this tests repository. Release contract pins the reviewed skill commit. Draft PRs are review artifacts, not merges, package-store publication or deployment. Binary evidence is never re-uploaded to work around a pending approval.
