(Mesa 25.0.7, LLVM 19.1.7). Real Khronos Validation Layer 1.4.309 emits
`VUID-VkBufferCreateInfo-size-00912` for size=0. Callback returns VK_TRUE,

NOT system scheduling acquisition, GPU timing or resource-generation mapping.

that removes size=0 exits 5. Both prevent a false successful bad-case report.
Packages came from official Debian archive and hashes match package metadata.
Tool binaries and raw callbacks/traces remain local. Checked summary and
reproduction sources are committed; no third-party binaries are distributed.

This closes a narrow real validation + trace-processing integration gap,
not full M3, Live, real-engine repair, target device validation or final release.
