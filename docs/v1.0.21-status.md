| GPU-driven 可见对象 | 固定对象 ID 3、5、9。仅在已声明允许无序且代际相同的诊断中接受置换；缺失、重复或错误代际拒绝或判为不同。缺代际、未声明无序或已知 overflow 时不得确认完整匹配。故意忽略代际比较，C++ 负控在对应断言中退出 134 |
