## Reproduce static and simulation

```sh
export VULKAN_SKILL_ROOT=/path/to/clean/pinned/skill
python -m pytest -q -m static tests
python -m pytest -q -m snapshot tests
python -m pytest -q -m live tests
python tests/media_surface_lab.py
```

The Media Surface Lab is an **isolated Python state fixture**, not an Android APK,
Java/JNI implementation or Vulkan execution. It simulates 100 local output rebuilds
and 1,000 two-consumer leases, checks stale generations, acknowledged Surface stop,
failed FD import/submit/export, FD 0, double close/return, bounded backlog and per-output
color gates. It cannot establish GPU synchronization, API compatibility, real FD or
allocation convergence, runtime speed, device recovery or HDR/alpha pixel accuracy.

The planned device smoke includes 100 rebuilds, 1,000 frames and 15 minutes sustained
operation. Freeze target budget before actual execution; never count the fast Python
simulation as the 15-minute device test. Device source/APK and hardware are unavailable
in this candidate; reference scenario and state fixture are the executable subset.
