# v1.0.10 acceptance commands and limits

`v1.0.10-traceability.json` maps the exact plan to implementation and pending gates.
This is a candidate, not a release PASS. Final evidence must name the committed
skill SHA, tests SHA and source tree. Pin release-contract.json before running.

From the tests repository, with `VULKAN_SKILL_ROOT` set to the clean paired skill:

```sh
python -m pytest -q -m static tests
python -m pytest -q -m snapshot tests
python -m pytest -q -m live tests
node "$VULKAN_SKILL_ROOT/scripts/check-skill.mjs"
python "$VULKAN_SKILL_ROOT/scripts/host_contract.py"
python -m unittest discover -s "$VULKAN_SKILL_ROOT/scripts" -p 'test_*.py'
python "$VULKAN_SKILL_ROOT/scripts/agensi_audit_and_pack.py" "$VULKAN_SKILL_ROOT" --out /tmp/vulkan-final-a.zip
python "$VULKAN_SKILL_ROOT/scripts/agensi_audit_and_pack.py" "$VULKAN_SKILL_ROOT" --out /tmp/vulkan-final-b.zip
sha256sum /tmp/vulkan-final-a.zip /tmp/vulkan-final-b.zip
```

Use fresh nonexisting output paths. Retain both JSON packer reports and compare
ZIP hashes. The packer rejects dirty source trees and refuses output overwrite.
No configured model wrapper exists in the current environment. When an authorized
real adapter and exact model become available, use clean committed checkouts:

```sh
python tests/run_live_model_behavior.py --expected-skill-sha FULL_SHA \
  --output-dir /tmp/vulkan-live-new-run --require-live --check
python tests/measure_context.py --baseline-run V108_RUN --candidate-run CANDIDATE_RUN \
  --candidate-sha FULL_SHA
python tests/measure_context.py --baseline-run V109_RUN --candidate-run CANDIDATE_RUN \
  --candidate-sha FULL_SHA --comparison v109-regression
```

Configure adapter/model/parameters through the documented environment variables;
do not embed credentials in reports. Run each of the 16 cases once for smoke;
release stability recommends three runs per case with unchanged model/parameters.
Retain raw immutable outputs, reads, hashes and provider usage, then separately
review semantics. Verify at least one real host's discovery/load/route/section
trace plus the four Agensi manual topics (Android black screen, synchronization,
performance, architecture). Illustrative YAML and unit mocks cannot satisfy these.
No credentials, host calls, GPU execution, marketplace upload or main merge have
been performed by this tests implementation. Any correctness-only release still
requires an explicit acceptance decision; this document does not authorize one.

The no-command availability manifest exits before resolving candidate SHA; it is
only environment availability evidence, never SHA-bound acceptance. Record the
final candidate SHA and tests code tree in the execution report; report-only
commits are listed separately to avoid circular self-referential commit claims.
